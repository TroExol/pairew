# Pairew

**Swipe, vote, and find a film everyone actually wants to watch.**

Picking a film with someone takes longer than the film. Pairew turns it into a few seconds of swiping:
everyone swipes independently, and the app surfaces the matches.

**[Try it →](https://pairew.vercel.app)**

## Tech stack

| Layer | Technologies |
|-------|--------------|
| **Framework** | Next.js (App Router), React, TypeScript |
| **Styling** | Tailwind CSS, PostCSS |
| **Quality** | ESLint (flat config), Husky pre-commit hooks |
| **Deployment** | Vercel |

## Getting started

### Requirements

- Node.js — see `.nvmrc`

### Setup

```bash
npm install
npm run dev
```

The app runs at http://localhost:3000.

### Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm start` | Serve the production build |
| `npm run lint` | Lint the project |
