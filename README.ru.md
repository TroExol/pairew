# Pairew

**Свайпайте, голосуйте и находите фильм, который действительно хотят посмотреть все.**

Выбор фильма вдвоём занимает больше времени, чем сам фильм. Pairew превращает это в несколько секунд свайпов: каждый свайпает независимо, приложение показывает совпадения.

**[Попробовать →](https://pairew.vercel.app)**

## Стек технологий

| Слой | Технологии |
|------|-----------|
| **Фреймворк** | Next.js (App Router), React, TypeScript |
| **Стили** | Tailwind CSS, PostCSS |
| **Качество** | ESLint (flat config), Husky pre-commit хуки |
| **Деплой** | Vercel |

## Быстрый старт

### Требования

- Node.js — версия указана в `.nvmrc`

### Установка

```bash
npm install
npm run dev
```

Приложение поднимется на http://localhost:3000.

### Команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Дев-сервер |
| `npm run build` | Продакшен-сборка |
| `npm start` | Запуск продакшен-сборки |
| `npm run lint` | Линт проекта |
